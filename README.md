# static-online-form
A modern, responsive online application form designed for the CINTEL Association technical domain. The form collects applicant details such as name, email, academic year, preferred technical domain, skills and knowledge, availability, and areas they want to build or learn.

The frontend includes required-field validation, clear error messages, responsive UI, loading and success states, and a midnight campus-glow design. Submitted responses are securely stored in a Supabase PostgreSQL database.

An authenticated admin dashboard is also included, allowing CINTEL administrators to view the total number of applicants, filter and search responses, review applicant details, refresh submissions, and export the data as CSV.
